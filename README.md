# Cowork

## Descripción

**Cowork** es una aplicación web enfocada en la gestión, alquiler y reserva de espacios de trabajo compartido. La plataforma facilita la conexión entre propietarios de espacios y profesionales, permitiendo buscar disponibilidad, visualizar detalles de los inmuebles y gestionar reservas de forma eficiente.

## Stack Tecnológico

Este proyecto ha sido desarrollado utilizando tecnologías modernas para garantizar escalabilidad y un rendimiento óptimo:

* **Backend:** [Laravel](https://laravel.com/) (PHP), encargado de gestionar la lógica de negocio, la API RESTful y la autenticación.
* **Frontend:** [Next.js](https://nextjs.org/) (React), proporcionando una interfaz de usuario dinámica y optimizada.
* **Base de datos:** [PostgreSQL](https://www.postgresql.org/), utilizada para el almacenamiento estructurado y seguro de la información.

## Características Principales

* **Buscador de espacios:** Filtros para encontrar el lugar de trabajo ideal.
* **Sistema de reservas:** Gestión de disponibilidad y confirmación de espacios en tiempo real.
* **Gestión de perfiles:** Panel para usuarios donde pueden consultar su historial y detalles de sus reservas.
* **Arquitectura desacoplada:** Comunicación eficiente entre el frontend de Next.js y el backend de Laravel.

## Requisitos previos

* PHP 8.x
* Composer
* Node.js y npm/yarn
* PostgreSQL
